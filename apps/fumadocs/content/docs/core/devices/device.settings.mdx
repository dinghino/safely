---
title: Settings
---

Each device has a set of predefined settings that are derived from the type of device
it is and the capabilities it has.

These settings can be partially customized by the user from the device settings page,
but the implementation details are kept abstracted to avoid confusion and complexity.

## Common settings

These are core settings that are common to most device types and can be adjusted
by the user to specify various preferences, like notification settings, privacy options,
and other device-specific configurations.

## Geolocation options

A user may partially customize the geolocation options for each devices through
some abstracted settings, based of the various `tracking modes` that are available,
allowing them to customize each device to their actual needs and use cases.
