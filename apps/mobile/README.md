# Safely mobile app

This is the mobile app for safely. it is in early development stage.

## Development

- follow instructions on the [expo docs](https://docs.expo.dev/workflow/android-studio-emulator/) to set up `adb` and emulator
- run `bun run android` depending on your platform

As the time of writing there is no script to run the app from the monorepo's root
since that requires `adb` to be present on the device and we don't want to bother people working on
the web functionalities.
