# Data filter system

This module contains a filtering system that is derived from <https://ui.bazza.dev/docs/data-table-filter>.
The framework exposes an independent system to manage filtering states, ui elements and
integrations with tanstack's react-table.

Whilst the official documentation is valid, the system itself is going to be modified
and expanded for our needs, so some functionalities may differ.
