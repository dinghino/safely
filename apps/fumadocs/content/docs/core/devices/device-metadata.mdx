title: Device information
description: What we collect
---

Most of the information collected about a user device is for two main reasons:

1. analytics and development, to help guide the developoment of new features and
   optimization of existing ones
2. to let the system determine what each device can do and how both the user and
   the system itself can interact with it.
   A prime example of this is knowing if your device has GPS capabilities or not,
   so that the system can decide if it is possible to use it for tracking, geolocated
   notifications and other features.

## Information collected

<Callout type="info">
  All the information collected depends on the device and permissions provided
  and is always visible to the user to know what is being collected.
</Callout>

Depending on the device itself the app collects information such as:


- Device model and manufacturer
- Operating system and version
- App version
- Capabilities (GPS, Bluetooth, NFC, etc)
- Language and locale
- Timezone
- Network information (type of connection, carrier, etc)
- Battery status

<Callout type="info">
  We do not collect any personal information about the user or the device, such as
  contacts, messages, photos, etc.
</Callout>
